# Mission Room

Builds, measures and validates **Side Bets — Missions** economy bundles for blackjack.

Live: https://gilmisgav.github.io/mission-room/

Single self-contained page — the 29-type mission bank measured by simulation against a
4,000-deck sample, difficulty tiers, target sizing, a bundle builder with full upload
validation, the long-chase token bar, and a deck maker that generates the scripted deck
list for each day of a run with cumulative mission progress per deck.
